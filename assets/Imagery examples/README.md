# Imagery examples

The example pictures of the section *Imagery guide*, moved here from the uWeed Imagery Master Guide on 25 November 2026. Each file is named in the guide where it explains a rule; its caption there says whether it is a current reference, an accepted exception or a historical study.

- `effects-*`: effects blog headers (Sport S3 detail reference, Schlaf, Schmerzen, and the two approved one-photo exceptions).
- `blog-*`, `city-collage-historical`: other blog compositions and the superseded city collage study.
- `category-*`: the selected CBD Blüten engraving reference, the historical category proposal and the category education examples.
- `inline-*`: the explanatory-graphic layout library (sequence, comparison, annotated, Q&A, takeaway) and the desktop-to-mobile reflow study.

These are references for how images look, not files to publish. Live images stay in WordPress and in the Drive folders the guide names. Most are review-resolution studies, not production masters.
